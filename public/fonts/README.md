# Fonts Folder

Coloca los archivos de fuente de **Studio Feixen** aquí para cargarlos localmente de manera automática:

- `StudioFeixenSans-Variable.woff2` / `.ttf`
- `StudioFeixenSans.woff2` / `.ttf`
- `StudioFeixen.woff2` / `.ttf`

Los archivos `@font-face` están configurados en `app/globals.css` bajo la variable CSS `--font-feixen`.
